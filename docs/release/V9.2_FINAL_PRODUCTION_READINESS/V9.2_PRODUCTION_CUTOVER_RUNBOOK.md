## 5. Rollback Triggers & Abort Procedure

If any of the following abort criteria occur during the cutover window:
- Migration script fails with an unrecoverable SQL error.
- Next.js production container fails health check `/api/health` after 3 restart attempts.
- Core authentication fails or `AUDIT_CHECKPOINT_HMAC_SECRET` produces crypto error.
- Data corruption detected in pre-migration verification.

### Emergency Abort Procedure:
1. Announce immediate abort on release bridge.
2. If migrations were applied, run matching rollback SQL scripts:
   - `20261105000001_v9_2_comprehensive_enterprise_hardening_rollback.sql`
   - `20261031000003_v9_2_enterprise_security_and_audit_rollback.sql`
   - `20261031000002_v9_2_technical_evaluations_and_sources_rollback.sql`
   - `20261031000001_v9_2_enterprise_proforma_challan_and_automation_rollback.sql`
3. If database state is indeterminate, restore cold snapshot `icon_prod_pre_cutover_backup.sql`.
4. Point routing back to stable baseline application release.
5. Re-enable public traffic and broadcast maintenance resolution notification.
6. Conduct incident post-mortem within 24 hours.
